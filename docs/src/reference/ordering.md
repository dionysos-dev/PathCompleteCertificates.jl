# Ordering reference

Is one graph guaranteed no worse than another for a template, whatever the
system? The question of [debauche2021comparison](@cite), Def. 4, answered here
by three procedures that are relaxations of one another — a map, a relation, a
matrix — each complete for the closure it serves. The subset lifts of the
[Lift reference](@ref) are the exhibits of these decisions; none is built to
decide.

Reads graphs, a template's closure declarations and, for the addition-closed
case, a linear program, so it belongs to neither axis, like [`common`](@ref).
