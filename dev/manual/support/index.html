What works with what

Every template composes with every problem in principle. In practice, stability runs on all seven templates, and the two other problems on the quadratic one.

StabilityProblemSafetyProblemOptimalControlProblem
QuadraticTemplate✓✓✓
LinearCopositiveTemplate✓ ¹✗✗
DualCopositiveTemplate✓ ¹✗✗
PolyhedralTemplate✓✗✗
ConicPolyhedralTemplate✓✗✗
SumOfSquaresTemplate✓ ²✗✗
SetProgTemplate✓ ²✗✗

¹ Positive systems only: entrywise nonnegative mode matrices.

² Behind a package extension: using SumOfSquares first, or using SetProg for SetProgTemplate, or its primitives are not defined.

A ✗ throws an ArgumentError before any model is built. Optimal control needs a complete graph, not merely a path-complete one. Stability accepts a WordGraph; safety and optimal control need one mode per edge.

Comparing and refining

compare is written for stability, where the theory is; it asks a question about graphs, and which of its verdicts hold for a template is read from the template's closure properties. refine runs on stability and safety, for every template that answers domination_slack, which is how the loop reads where a certificate is tight:

refinelifts valid for compare
QuadraticTemplate✓identity, sum; composition if invertible
LinearCopositiveTemplate✓ ¹identity, sum, min without closure; composition if nonnegative with no zero column
DualCopositiveTemplate✓ ¹identity, max; sum through its dual
PolyhedralTemplate✓identity; max when the node matrices coincide
ConicPolyhedralTemplate✓identity
SumOfSquaresTemplate✗ ³identity, sum; composition if invertible
SetProgTemplate✗ ³identity; sum when the nodes share the set variable

³ No domination_slack yet, so the loop cannot read where these templates are tight.

The gaps

Safety with the polyhedral templates is possible in principle, by the same construction in homogeneous coordinates; it is not implemented. Optimal control is tied to the quadratic template by the mathematics, the substitution $S = P^{-1}$, $Y = KS$ that makes it convex ((Ninite et al., 2026)). A new template gives the whole stability column at once, and the two other problems once it answers their primitives; see the developer conventions.
