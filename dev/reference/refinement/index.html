Refinement reference

A refinement transforms a path-complete graph into one that is no worse for every template. refine applies refinements repeatedly where a certificate is tight; see Graph improvement via refinements.

The interface

PathCompleteCertificates.AbstractRefinement — Type
AbstractRefinement

A transformation of a path-complete graph into a path-complete graph that is no worse for every template.

source
PathCompleteCertificates.Refined — Type
Refined(graph, origins)

The refined graph and, for each of its nodes, the node of the original it came from.

source
PathCompleteCertificates.origins — Method
origins(refined)

Where each node of a Refined or a Lifted graph came from.

source
PathCompleteCertificates.refine — Function
refine(refinement, graph, edge_list) -> Refined
refine(refinement, graph) -> Refined

Apply refinement at the edges of edge_list; without them, a local refinement is applied at every edge and a global one to the whole graph.

The catalogue

PathCompleteCertificates.ForwardEdgeSplit — Type
ForwardEdgeSplit()

Split the source of each given edge into a copy owning that outgoing edge and every incoming edge; a given self-loop goes from its copy to the node. A node whose outgoing edges are all given is replaced by its copies.

source
PathCompleteCertificates.BackwardEdgeSplit — Type
BackwardEdgeSplit()

Split the destination of each given edge into a copy owning that incoming edge and every outgoing edge. The dual of ForwardEdgeSplit.

source
PathCompleteCertificates.ForwardEdgeProduct — Type
ForwardEdgeProduct()

Replace each given edge (s, d, w) by the edges (s, d′, w·u) for every edge (d, d′, u), in a WordGraph on the same nodes. Throws when d has no outgoing edge.

source
PathCompleteCertificates.BackwardEdgeProduct — Type
BackwardEdgeProduct()

Replace each given edge (s, d, w) by the edges (s′, d, u·w) for every edge (s′, s, u). The dual of ForwardEdgeProduct.

source
PathCompleteCertificates.PathDependentRefinement — Type
PathDependentRefinement(k)

BackwardEdgeSplit at every edge, k times: nodes are the paths of length k, and origins records the last node of each.

source
PathCompleteCertificates.ProductRefinement — Type
ProductRefinement(T)

The same nodes, and one edge per path of length T labelled by its word, as a WordGraph.

source

Strategies

PathCompleteCertificates.Hierarchy — Type
Hierarchy(step)

step, a refinement or a lift, applied to the whole graph as the only candidate. A lift throws unless it is_valid for the template on the system.

source
PathCompleteCertificates.RefineTightEdges — Type
RefineTightEdges(refinements = (ForwardEdgeSplit(), BackwardEdgeSplit(),
                                ForwardEdgeProduct(), BackwardEdgeProduct()))

Every refinement of refinements at every tight edge where it changes the graph, as candidates; meant for select = :best in refine.

source
PathCompleteCertificates.SplitTightNode — Type
SplitTightNode(refinement = ForwardEdgeSplit(); rng = nothing)

Apply refinement to the outgoing edges of the node with the most tight outgoing edges, or propose no candidate when no node has two. With rng, ties are broken at random.

PathCompleteCertificates.refine — Method
refine(template, problem; optimizer, kwargs...)
refine(template, graph, problem; optimizer, strategy = SplitTightNode(),
       select = :first, stop = Returns(false), depth_max = 5, stall_max = 1,
       atol = 1e-4, gap_tol = 1e-6, rtol = 1e-6, path_complete = true,
       kwargs...)

Refine graph, by default common_graph of the system, until the optimality_gap of its certificate closes; returns a RefinementTrace.

  • strategy(certificate; atol) returns candidate Refined graphs, best first.
  • select = :best solves every candidate and keeps the lowest objective; :first takes the first.
  • The run stops when stop(certificate) holds, the gap is at most gap_tol, stall_max steps in a row fail to improve the objective by rtol, depth_max certificates are solved, or no candidate is left.
  • rtol is the solve tolerance and atol decides tightness, with atol ≥ 10 rtol.
  • path_complete = false skips the path-completeness check of the starting graph.

Other keywords go to best_certificate.
