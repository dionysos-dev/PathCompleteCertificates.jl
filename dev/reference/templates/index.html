Template reference

A template is a SetProg family. The constructors below build the families that Choosing a template presents, and stability also accepts SetProg families directly; What works with what says which problems each supports.

Constructors

PathCompleteCertificates.QuadraticFunction — Type
QuadraticFunction(P)

The quadratic form $V(x) = x^\top P x$, a fitted node function of optimal control. Matrix(V) is $P$. Stability and safety return native SetProg sets instead: see QuadraticTemplate.

source
PathCompleteCertificates.QuadraticTemplate — Method
QuadraticTemplate()

The quadratic forms $V(x) = x^\top P x$, as the SetProg family Ellipsoid(symmetric = true). It applies to every system and every problem, and gives semidefinite programs.

For stability, a fitted node function V is a SetProg ellipsoid: evaluate it with node_value, and read $P$ as V.Q. The conditioning_bound keyword of certify bounds $P$ between $I$ and conditioning_bound times $I$. Safety returns affine SetProg quadratics; optimal control returns a QuadraticFunction per node. See Choosing a template.

source
PathCompleteCertificates.SumOfSquaresTemplate — Method
SumOfSquaresTemplate(degree, variables; min_scale = 1)

The sums of squares $V(x) = \sum_j q_j(x)^2$, each $q_j$ a homogeneous polynomial of degree degree in the polynomial variables, so that $V$ has degree 2degree, as a SetProg PolySet; degree = 1 gives the quadratic forms. It applies to every system, for stability, gives semidefinite programs, and needs using SumOfSquares.

Each node function is min_scale * sum(x .^ 2)^degree plus a sum of squares, which excludes $V \equiv 0$. refine does not run on this template: its edge slacks are not implemented. See Choosing a template.

source
PathCompleteCertificates.ConicPolyhedralTemplate — Method
ConicPolyhedralTemplate(node_partitions; min_scale = 1)

The polyhedral functions linear on each cone over the facets of a polytope, as one SetProg polytope per node, with the polytope of each node in node_partitions; each polytope must contain the origin in its interior, and planar_conic_partition builds one in the plane. It applies to every system, for stability, and gives linear programs. min_scale normalizes the node functions: each is at least min_scale times the function equal to one on the boundary of its polytope.

source
PathCompleteCertificates.DualCopositiveFunction — Method
DualCopositiveFunction(v)

The function $V(x) = \max_i x_i / v_i$ on the nonnegative orthant, a node function of DualCopositiveTemplate, as a SetProg set; evaluate it with node_value.

source
PathCompleteCertificates.DualCopositiveTemplate — Method
DualCopositiveTemplate(; min_weight = 1)

The functions $V(x) = \max_i x_i / v_i$ on the nonnegative orthant, the duals of those of LinearCopositiveTemplate, as a SetProg polytope on that orthant. It applies to positive systems, for stability, and gives linear programs. min_weight normalizes the node functions: every weight $v_i$ is at least min_weight.

source
PathCompleteCertificates.LinearCopositiveFunction — Method
LinearCopositiveFunction(c)

The function $V(x) = c^\top x$ on the nonnegative orthant, a node function of LinearCopositiveTemplate, as a SetProg set; evaluate it with node_value.

source
PathCompleteCertificates.LinearCopositiveTemplate — Method
LinearCopositiveTemplate()

The linear functions $V(x) = c^\top x$ on the nonnegative orthant, as a SetProg polytope on that orthant. It applies to positive systems, whose matrices have nonnegative entries, for stability, and gives linear programs. Its dual is DualCopositiveTemplate. See Choosing a template.

source
PathCompleteCertificates.ParallelFacesPolyhedralFunction — Method
ParallelFacesPolyhedralFunction(G, w)

The function $V(x) = \max_k |(G x)_k| / w_k$, a node function of ParallelFacesPolyhedralTemplate, as a SetProg set; evaluate it with node_value.

source
PathCompleteCertificates.ParallelFacesPolyhedralTemplate — Method
ParallelFacesPolyhedralTemplate(n_nodes, dimension; min_weight = 1)
ParallelFacesPolyhedralTemplate(matrices; min_weight = 1)

The polyhedral functions $V(x) = \max_k |(G x)_k| / w_k$, whose faces come in parallel pairs, normal to the rows of $G$, as one SetProg polytope per node: $G$ is the identity, of size dimension, at each of n_nodes nodes, or one of the invertible matrices per node. The weights $w$ are the variables. It applies to every system, for stability, and gives linear programs. min_weight normalizes the node functions: every weight is at least min_weight.

source
PathCompleteCertificates.planar_conic_partition — Method
planar_conic_partition(order; library = nothing)

A partition of the plane for ConicPolyhedralTemplate: a centrally symmetric polygon with 8 * 2^(order - 1) facets. The cones over its facets lie between the rays of $(1, 0)$, $(1, 1)$, $(0, 1)$, $(-1, 1)$ and their opposites, each split in two at every further order by the sum of its two rays. library gives a Polyhedra library, with a linear programming solver.

The template interface

What a template provides to a problem: the primitives that build its node functions and edge inequalities, and what the package needs to know about it. Extending the package says which to implement for a new family.

PathCompleteCertificates.add_decrease! — Function
add_decrease!(model, template, V_src, V_dst, map; scale = 1)

The decrease condition of an edge: V_dst after map is at most scale times V_src. Constrain, for every $x$, $\text{scale} \cdot V_{src}(x) \ge V_{dst}(\text{map} \cdot x)$; for a SetProg family, as a set inclusion.

source
PathCompleteCertificates.add_function_variables! — Function
add_function_variables!(model, template, dimension, node)

Add the variables of the node function at node, with the constraints that make it a member of the template, and return the function.

source
PathCompleteCertificates.add_normalization! — Function
add_normalization!(model, template, V; conditioning_bound = Inf)

Constrain V to be positive away from the origin, at a fixed scale, which excludes the trivial function V ≡ 0: its set contains, or lies in, a fixed reference set. For an ellipsoid, a finite conditioning_bound also bounds its matrix by conditioning_bound * I.

source
PathCompleteCertificates.decrease_slack — Function
decrease_slack(template, V_src, V_dst, map; scale = 1)

The slack of the decrease condition scale · V_src(x) ≥ V_dst(map · x) for fitted node functions: nonnegative when it holds, zero exactly when it is tight. It is in the units of the fitted functions, so compare slacks within one certificate only. Not implemented for polynomial and piecewise-quadratic families, whose slacks would need an optimization of their own.

source
PathCompleteCertificates.has_dual — Function
has_dual(template) -> Bool

Whether dual(template) and dual(template, V) are defined; false by default. The quadratic template is its own dual, and the two copositive templates are each other's.

source
PathCompleteCertificates.homogeneity_degree — Function
homogeneity_degree(template) -> Int

The degree p such that V(cx) = cᵖ V(x) for every function of the template.

source
PathCompleteCertificates.is_applicable — Function
is_applicable(template, system) -> Bool

Whether template applies to the dynamics of system; true by default. The copositive templates apply to positive systems only. A problem refuses a template that does not apply, and no lift is valid for it.

source
PathCompleteCertificates.is_closed_under — Function
is_closed_under(template, operation, system) -> Bool

Whether combining members of the template by operation gives a member; false by default. system matters only for Composition and InverseComposition.

source
PathCompleteCertificates.reindex — Function
reindex(template, origins)

The template for a lifted graph whose nodes come from origins. A single template is unchanged; a vector, one template per node, follows origins, and throws if a node merges origins with different templates.

source
PathCompleteCertificates.solution_value — Function
solution_value(template, V)

The node function V after optimize!, with values in place of variables: for a SetProg family, the fitted set.

source

SetProg families

The families of SetProg, which the constructors return and stability accepts directly. Safety accepts quadratic and polynomial families.

SetProg.Domain — Type
Domain(set, domain)

Restrict a set variable family to a fixed polyhedral domain, constructing a Sets.Intersection when the variable is instantiated. Accepts a Polyhedra representation or polyhedron, MOI.Nonnegatives(n), or MOI.Nonnegatives to infer the orthant dimension from the model. The domain restricts the gauge in the selected modeling space: dual modeling returns the polar of the restricted gauge. Supported constraints depend on the resulting intersection.
