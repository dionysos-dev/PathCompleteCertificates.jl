Template reference

Stability takes SetProg families directly. See Templates for their parameters and What works with what for support by problem.

SetProg families

SetProg.Domain — Type
Domain(set, domain)

Restrict a set variable family to a fixed polyhedral domain, constructing a Sets.Intersection when the variable is instantiated. Accepts a Polyhedra representation or polyhedron, MOI.Nonnegatives(n), or MOI.Nonnegatives to infer the orthant dimension from the model. The domain restricts the gauge in the selected modeling space: dual modeling returns the polar of the restricted gauge. Supported constraints depend on the resulting intersection.

Quadratic compatibility template

QuadraticTemplate() returns a native SetProg ellipsoid family. Stability returns native fitted ellipsoids. Safety and optimal control retain their matrix implementations behind a private adapter.

PathCompleteCertificates.QuadraticFunction — Type
QuadraticFunction(P)

A fitted quadratic V(x) = x'Px, used by safety and optimal control. Matrix(V) is P. Stability returns native SetProg ellipsoids instead.

source
PathCompleteCertificates.QuadraticTemplate — Method
QuadraticTemplate()

Return SetProg.Ellipsoid(symmetric = true), the native family of homogeneous quadratic gauges. Stability returns fitted SetProg ellipsoids; evaluate them with node_value(problem, V, x) and access their matrices as V.Q. Use the conditioning_bound keyword of certify or jsr_bound to cap the coefficient matrix. Safety and optimal control retain their matrix models.

Compatibility constructors

SumOfSquaresTemplate and the former polyhedral templates return native SetProg families. Their names remain in PCC; there are no separate SetProg template types.

PathCompleteCertificates.ConicPolyhedralTemplate — Method
ConicPolyhedralTemplate(node_partitions; min_scale = 1)

One SetProg polytope per node. Each partition polytope describes the cones over its facets and must contain the origin in its interior. min_scale scales the partition's gauge used for normalization.

PathCompleteCertificates.planar_conic_partition — Method
planar_conic_partition(order; library = nothing)

Return a centrally symmetric partition polytope with 8 * 2^(order - 1) facets. The cones over its facets have the same boundary rays as the planar conic partition. library can supply a Polyhedra library with an LP solver.

source
PathCompleteCertificates.SumOfSquaresTemplate — Method
SumOfSquaresTemplate(degree, variables; min_scale = 1)

Construct a native SetProg PolySet of homogeneous SOS polynomials of degree 2degree, using the shared polynomial variables. Its gauge is min_scale * sum(variables .^ 2)^degree plus an SOS remainder, so min_scale fixes the normalization. Requires using SumOfSquares. Decrease slacks and refinement are not implemented for polynomial sets.
