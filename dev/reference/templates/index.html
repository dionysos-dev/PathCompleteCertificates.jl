Template reference

A template is the family the node functions are drawn from. See Templates for the concepts, and What works with what for which problems accept each one.

The interface

PathCompleteCertificates.AbstractTemplate — Type
AbstractTemplate

A family of candidate node functions, passed as an instance such as QuadraticTemplate().

source
PathCompleteCertificates.add_decrease! — Function
add_decrease!(model, template, V_src, V_dst, map; scale = 1)

The decrease condition of an edge: V_dst after map is at most scale times V_src. Constrain, for every $x$, $\text{scale} \cdot V_{src}(x) \ge V_{dst}(\text{map} \cdot x)$.

source
PathCompleteCertificates.add_function_variables! — Function
add_function_variables!(model, template, dimension, node)

Add the variables of the node function at node, with the constraints that make it a member of the template, and return the function.

source
PathCompleteCertificates.add_normalization! — Function
add_normalization!(model, template, V)

Constrain V to be positive away from the origin, at a fixed scale, which excludes the trivial function V ≡ 0.

source
PathCompleteCertificates.decrease_slack — Function
decrease_slack(template, V_src, V_dst, map; scale = 1)

The slack of the decrease condition scale · V_src(x) ≥ V_dst(map · x) for fitted node functions: nonnegative when it holds, zero exactly when it is tight. It is in the units of the fitted functions, so compare slacks within one certificate only.

source
PathCompleteCertificates.dual — Method
dual(template, V)

The dual norm of a fitted node function V, as a member of dual(template).

source
PathCompleteCertificates.has_dual — Method
has_dual(template) -> Bool

Whether dual(template) and dual(template, V) are defined; false by default.

source
PathCompleteCertificates.homogeneity_degree — Function
homogeneity_degree(template) -> Int

The degree p such that V(cx) = cᵖ V(x) for every function of the template.

source
PathCompleteCertificates.is_applicable — Method
is_applicable(template, system) -> Bool

Whether template applies to the dynamics of system; true by default. A problem refuses a template that does not, and no lift is valid for it.

source
PathCompleteCertificates.is_closed_under — Method
is_closed_under(template, operation, system) -> Bool

Whether combining members of the template by operation gives a member; false by default. system matters only for Composition and InverseComposition.

source
PathCompleteCertificates.reindex — Method
reindex(template, origins)

The template for a lifted graph whose nodes come from origins. Throws if a node merges origins with different per-node data.

source
PathCompleteCertificates.solution_value — Function
solution_value(template, V)

The node function V after optimize!, with values in place of variables.

Quadratic

PathCompleteCertificates.QuadraticFunction — Type
QuadraticFunction(P)

A fitted node function V(x) = x'Px of a QuadraticTemplate; Matrix(V) is P.

source
PathCompleteCertificates.QuadraticTemplate — Type
QuadraticTemplate(; conditioning_bound = Inf)

The template $V(x) = x^\top P x$, with $P$ positive definite.

A finite conditioning_bound also imposes $P_s \preceq \text{conditioning\_bound} \cdot I$, which can exclude every certificate of a stable system.

source
PathCompleteCertificates.LinearCopositiveTemplate — Type
LinearCopositiveTemplate()

The template $V(x) = c^\top x$ on the nonnegative orthant, for positive systems only.

Dual copositive

PathCompleteCertificates.DualCopositiveFunction — Type
DualCopositiveFunction(v)

A node function V(x) = max_i x_i / v_i of a DualCopositiveTemplate.

source
PathCompleteCertificates.DualCopositiveTemplate — Type
DualCopositiveTemplate(; min_weight = 1)

The template $V(x) = \max_i x_i / v_i$ on the nonnegative orthant, with every $v_i$ at least min_weight: the dual of LinearCopositiveTemplate. For positive systems only. The program is homogeneous, so min_weight only fixes its scale; a much smaller one lets the solver's absolute tolerance show in the rate.

Polyhedral, fixed facets

PathCompleteCertificates.ParallelFacesPolyhedralFunction — Type
ParallelFacesPolyhedralFunction(G, w)

A node function V(x) = max_k |(Gx)_k| / w_k of a ParallelFacesPolyhedralTemplate.

source
PathCompleteCertificates.ParallelFacesPolyhedralTemplate — Type
ParallelFacesPolyhedralTemplate(G; min_weight = 1)
ParallelFacesPolyhedralTemplate(n_nodes, dimension; min_weight = 1)

The polytopes with pairs of parallel faces of Athanasopoulos and Jungers (2019), eq. (10): at node $s$,

\[V_s(x) = \max_k \frac{|(G_s x)_k|}{w_{s,k}},\]

where G holds one fixed invertible matrix per node (the identity by default) and the weights $w_{s,k}$, at least min_weight, are the variables. The program is homogeneous, so min_weight only fixes its scale; a much smaller one lets the solver's absolute tolerance show in the rate.

source

Polyhedral, free facets

PathCompleteCertificates.ConicPolyhedralFunction — Type
ConicPolyhedralFunction(cones, P, c)

A node function V(x) = max_i |(P x)_i| of a ConicPolyhedralTemplate, with V(x) ≥ c ‖x‖_∞.

source
PathCompleteCertificates.ConicPolyhedralTemplate — Type
ConicPolyhedralTemplate(cones; min_scale = 1)

The general polyhedral template: at node $s$,

\[V_s(x) = \max_i |p_{s,i}^\top x|,\]

with the rows of $P_s$ as variables. cones[s] partitions the state space into cones, one per row of $P_s$, each a matrix whose columns are its extreme rays; row $i$ is constrained to attain the maximum on cone $i$. min_scale is the lower bound on $c_s$ in $V_s(x) \ge c_s \|x\|_\infty$. The program is homogeneous, so min_scale only fixes its scale; a much smaller one lets the solver's absolute tolerance show in the rate.

source
PathCompleteCertificates.planar_conic_partition — Method
planar_conic_partition(order)

A partition of the upper half-plane into 4 * 2^(order - 1) cones, each a 2 x 2 matrix whose columns are its extreme rays; enough since the functions of ConicPolyhedralTemplate are symmetric.

source

Sum of squares

The primitives are defined in a package extension, so using SumOfSquares is required before this template can be solved with.

PathCompleteCertificates.SumOfSquaresFunction — Type
SumOfSquaresFunction(polynomial, variables)

A fitted node function of a SumOfSquaresTemplate: a polynomial in variables.

source
PathCompleteCertificates.SumOfSquaresTemplate — Type
SumOfSquaresTemplate(degree, variables; min_scale = 1)

The template of polynomials $V(x) = z(x)^\top Q z(x)$ with $Q \succeq 0$, where $z$ runs over the monomials of degree degree in the polynomial variables, shared by every node. min_scale is the lower bound on $c$ in $V(x) \ge c \|x\|^{2\,\text{degree}}$. Requires using SumOfSquares. The program is homogeneous, so min_scale only fixes its scale; a much smaller one lets the solver's absolute tolerance show in the rate. decrease_slack, hence edge_slacks, is not implemented, so refine does not run on it.

source

SetProg sets

The primitives are defined in a package extension, so using SetProg is required before this template can be solved with.

PathCompleteCertificates.SetProgFunction — Type
SetProgFunction(set)

A fitted node function of a SetProgTemplate, whose 1-sublevel set is set.

source
PathCompleteCertificates.SetProgTemplate — Type
SetProgTemplate(variable)
SetProgTemplate(variables::AbstractVector)

The template whose node function $V_s$ has as 1-sublevel set a SetProg set $S_s$; the edge inequality is the inclusion $(A / \gamma) S_{src} \subseteq S_{dst}$. variable is one of

variable$V_s(x)$Degree
Ellipsoid(symmetric = true)$x^\top Q_s x$2
PolySet(symmetric = true, degree = 2d, variables = x)a polynomial $p_s(x)$$2d$
Ellipsoid(symmetric = true, piecewise = P)$x^\top Q_{s,i} x$ on the $i$th cone2
Polytope(symmetric = true, piecewise = P)$a_{s,i}^\top x$ on the $i$th cone1

where the cones are over the facets of the polytope P, which must contain the origin in its interior. A vector gives one variable per node.

Requires using SetProg. Round the facet normals of P, since rounding errors can make an almost optimal solution violate the edge inequalities. decrease_slack, hence edge_slacks, is not implemented.
