Lift reference

A lift maps a path-complete graph to a path-complete graph whose nodes stand for combinations of the original nodes ((Debauche et al., 2022), Defs. 5 and 7). Lifts are used to compare graphs. When the lifted G simulates H, H is no worse than G for every template closed under the operation of the lift. compare tries every lift on a pair of graphs; see Graph comparison via lifts.

The interface

PathCompleteCertificates.AbstractLift — Type
AbstractLift

The lift of an Operation: a path-complete graph whose nodes are combinations of the original nodes. When lift(L, G) simulates H, G ≤_V H for every template closed under requirements(L).

source
PathCompleteCertificates.Lifted — Type
Lifted(graph, origins)

The lifted graph and, for each of its nodes, the original nodes it stands for.

source
PathCompleteCertificates.is_valid — Method
is_valid(L, template, system) -> Bool

Whether $G ≤_V L(G)$ for every path-complete $G$, for template on system. True when the template is closed under requirements(L), or its dual under requirements(dual(L)) on the dual system (Debauche, 2024; Prop. 7.5).

source
PathCompleteCertificates.lift — Function
lift(L, graph) -> Lifted

The lifted graph of graph, which must have one mode per edge.

source
PathCompleteCertificates.requirements — Method
requirements(L) -> Tuple

The Operations a template must be closed under for L to be valid on it.

source
PathCompleteCertificates.simulation — Method
simulation(L, G, H; optimizer = nothing)

The simulation of H by lift(L, G), or nothing when there is none; it proves G ≤_V H for every template closed under requirements(L) (Philippe and Jungers, 2019; Thm. 3.5), (Debauche, 2024; Thms. 7.18, 7.55, 7.56, 7.65 and 7.66). optimizer is used by SumLift() only.

source

DualLift(L)

The dual of the lift L: dual(L)(G) = dual(L(dual(G))).

The catalogue

PathCompleteCertificates.IdentityLift — Type
IdentityLift()

The lift that returns the graph; its simulation decides G ≤_V H for every template (Philippe and Jungers, 2019; Thm. 3.5).

source
PathCompleteCertificates.MinLift — Type
MinLift()

Nodes are the nonempty subsets, with an i-edge from A to B when every node of A has an i-edge into B. Requires Minimum, except for linear copositive norms on positive systems (Debauche, 2024; Thm. 7.43); its simulation is the greatest simulation relation (Debauche, 2024; Thm. 8.1).

source
PathCompleteCertificates.MaxLift — Type
MaxLift()

The dual of MinLift: nodes are the nonempty subsets, with an i-edge from A to B when every node of B is reached by an i-edge from A. Requires Maximum; its simulation is the relation on the dual graphs (Debauche, 2024; Thm. 8.5).

source
PathCompleteCertificates.SumLift — Type
SumLift(T)
SumLift()

The T-sum lift: nodes are the multisets of T nodes, with an i-edge from P to Q when the i-edges from P to Q admit a perfect matching. SumLift() stands for every T at once and is never built: simulation(SumLift(), G, H; optimizer) decides it (Debauche, 2024; Thm. 7.35 and Cor. 8.11) and returns an integer matrix C such that C·V is a certificate on H whenever V is one on G (Philippe et al., 2017; Def. IV.2 and Thm. IV.4). Requires Addition.

source
PathCompleteCertificates.CompositionLift — Type
CompositionLift(T)

The T-forward composition lift: a node (s, j₁, …, j_T) per node s and T-tuple of modes, and for each edge (a, b, i) an edge labelled j_T from (a, j₁…j_T) to (b, i, j₁…j_{T−1}). Requires Composition.

source
PathCompleteCertificates.BackwardCompositionLift — Type
BackwardCompositionLift(T)

The T-backward composition lift, the dual of CompositionLift(T). Requires InverseComposition.

source

Comparing two graphs

PathCompleteCertificates.Comparison — Type
Comparison

What compare returns: the lifts tried, the simulations found and the templates proved.

source
PathCompleteCertificates.compare — Method
compare(G, H; templates = (), system = nothing, optimizer = nothing, lifts = …)

Whether $G ≤_V H$, and for which of templates, as a Comparison. The sum lift is tried only with an optimizer, and system is required when templates is nonempty.

source
PathCompleteCertificates.lifts — Method
lifts(comparison)

The lifts compare tried, in order.

source
PathCompleteCertificates.simulations — Method
simulations(comparison)

The pairs lift => simulation, one per lift whose lifted first graph simulates the second.

source
PathCompleteCertificates.templates — Method
templates(comparison)

The given templates for which the second graph is proved no worse than the first.
