Systems and the common function

A switched system is the input to every problem. The common function, common, combines the node functions of a certificate into a single function. A certificate c is callable: c(x) evaluates its common function at x.

Trajectories and simulation

PathCompleteCertificates.Trajectory — Type
Trajectory

One run of a switched system: the states visited, the switching sequence taken and the inputs applied, nothing if there were none.

source

has_input(trajectory) -> Bool

Whether the run applied an input.

source
PathCompleteCertificates.inputs — Method
inputs(trajectory)

The inputs applied, one per step, or nothing for an open-loop run.

source
PathCompleteCertificates.states — Method
states(trajectory)

The states visited, oldest first, one more than the steps.

source
PathCompleteCertificates.switching — Method
switching(trajectory)

The modes taken: entry k carried states(trajectory)[k] to states(trajectory)[k + 1].

source
PathCompleteCertificates.simulate — Method
simulate(system, x0, modes; u = nothing)
simulate(system, x0, horizon::Integer; u = nothing, rng = Random.default_rng())

Run system from x0 along modes, or along horizon modes drawn uniformly at random, and return a Trajectory. u, a vector of inputs or a feedback law u(x), is required exactly when has_input(system); otherwise it throws.

source
PathCompleteCertificates.simulate — Method
simulate(certificate, x0, steps; rng = Random.default_rng(), node = nothing)

Run the closed loop under the policy of certificate along modes drawn uniformly at random, and return a Trajectory. The gain applied is that of the current graph node, which follows the observed modes from node, by default the node whose function is smallest at x0.

source

The common function

PathCompleteCertificates.common — Method
common(template, graph, problem, Vs, x)

The common function of the node functions Vs on graph, evaluated at x: a minimum of maxima of the Vs (Philippe et al., 2017). Depending on problem, a common Lyapunov function, a common barrier function or a bound on the value function. Calling a certificate c as c(x) evaluates it with the node functions of c.
