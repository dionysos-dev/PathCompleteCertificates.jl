Graph reference

A certificate is built on a labelled graph: a HybridSystems.GraphAutomaton, one mode per edge, or a WordGraph, one word per edge. See Path-complete graphs for what the predicates mean.

Queries

PathCompleteCertificates.CertificateGraph — Type
CertificateGraph

A graph a certificate is built on: a HybridSystems.GraphAutomaton, one mode per edge, or a WordGraph, one word per edge.

source
PathCompleteCertificates.WordGraph — Type
WordGraph(n_nodes)

A labelled graph whose edges carry words, finite sequences of modes. Safety, optimal control and common accept it only when every word is a single mode.

Word graphs

PathCompleteCertificates.expanded_form — Method
expanded_form(graph)

The graph with one mode per edge obtained by breaking every word edge (s, d, i₁…iₖ) into a chain s → m₁ → ⋯ → mₖ₋₁ → d through k − 1 new nodes. Nodes 1:n_nodes(graph) keep their number; the new ones follow.

dual(graph)

The dual graph: every edge s → d reversed into d → s, every word reversed. Path-completeness is preserved.

Simulation

PathCompleteCertificates.simulation — Method
simulation(G, H) -> Union{Nothing, Vector{Int}}

A map R from the nodes of H to those of G such that (R(a), R(b), i) is an edge of G for every edge (a, b, i) of H, or nothing if none exists.

source

Constructions

PathCompleteCertificates.de_bruijn — Method
de_bruijn(order, n_modes)

The De Bruijn graph of order l = order on n_modes modes. It has a node per sequence (i₁, …, iₗ) of the last l modes, newest first, and an edge labelled σ from (i₁, …, iₗ) to (σ, i₁, …, iₗ₋₁). It is complete, hence path-complete. The dual De Bruijn graph is dual(de_bruijn(order, n_modes)).

source
PathCompleteCertificates.common_graph — Method
common_graph(system)
common_graph(n_modes)

The graph of a common Lyapunov function: one node with a loop per mode.

source
PathCompleteCertificates.observer_graph — Method
observer_graph(graph) -> (observer, states)
observer_graph(graph, alphabet) -> (observer, states)

The observer graph of graph. Its nodes are nonempty subsets of the nodes of graph, starting from the set of all of them, and there is an edge (P, Q, σ) when Q is the set of successors by σ of the nodes in P. states[k] is the subset that observer node k stands for.

source
PathCompleteCertificates.simple_cycles — Method
simple_cycles(graph; max_length = n_nodes(graph))

Every simple cycle of graph with at most max_length edges, as the sequence of its edges.
