Graph reference

A certificate is built on a labelled graph: a HybridSystems.GraphAutomaton, one mode per edge, or a WordGraph, one word per edge. See Choosing a graph for what the predicates mean.

PathCompleteCertificates.WordGraph — Type

A labelled graph whose edges carry words, finite sequences of modes. Safety, optimal control and common accept it only when every word is a single mode.

Word graphs

PathCompleteCertificates.expanded_form — Method
expanded_form(graph)

The graph with one mode per edge obtained by breaking every word edge (a, b, i₁…iₖ) into a chain a → m₁ → ⋯ → mₖ₋₁ → b through k − 1 new nodes. Nodes 1:n_nodes(graph) keep their number; the new ones follow.

Constructions

PathCompleteCertificates.common_graph — Method
common_graph(system)
common_graph(n_modes)

The graph of a common Lyapunov function, one node with a loop per mode: the De Bruijn graph of order 0.

source
PathCompleteCertificates.de_bruijn — Method
de_bruijn(order, n_modes)

The De Bruijn graph of order l = order on n_modes modes. It has a node per sequence (i₁, …, iₗ) of the last l modes, newest first, and an edge labelled σ from (i₁, …, iₗ) to (σ, i₁, …, iₗ₋₁). It is complete, hence path-complete. Order 0 is common_graph. The dual De Bruijn graph is dual(de_bruijn(order, n_modes)).

source
PathCompleteCertificates.observer_graph — Method
observer_graph(graph) -> (observer, states)
observer_graph(graph, alphabet) -> (observer, states)

The observer graph of graph. Its nodes are nonempty subsets of the nodes of graph, starting from the set of all of them, and there is an edge (P, Q, σ) when Q is the set of successors by σ of the nodes in P. states[k] is the subset that observer node k stands for.
